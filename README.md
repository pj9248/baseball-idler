# Baseball Idler

Baseball Idler v0.4.1 Mobile — a touch-friendly baseball idle game built as a progressive web app.

## Play

After GitHub Pages is enabled, the intended project URL is:

`https://pj9248.github.io/baseball-idler/`

On iPhone, open the site in Safari, tap **Share**, then **Add to Home Screen**.

## Current features

- Plate appearances with baseball outcomes
- Outs, innings, occupied bases, scoring, wins/losses, extra innings and walk-offs
- Idle upgrade economy and offline progress
- Season/prestige progression
- Mobile-safe layout and touch controls
- Installable PWA metadata and offline caching
- Existing `baseballIdlerSave` localStorage save key retained

## Deployment

This repository includes `.github/workflows/pages.yml` for GitHub Pages deployment from `main`.

After the files are committed, open **Settings → Pages → Build and deployment → Source** and select **GitHub Actions** once. Future pushes to `main` will deploy automatically.
